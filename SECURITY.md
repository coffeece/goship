# Security

Please report vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/coffeece/goship/security/advisories/new),
not in a public issue. Include what you found, how to reproduce it and which
version (`goship version`) is affected.

You will get an answer within a few working days. Fixes are released as a
patch version and credited in the release notes unless you prefer otherwise.

Only the latest release is supported.
